# 人可读语义事实报告模板（report-template）

对话派生模式从机器可读事实集渲染本模板；内容与事实集一致（单一事实源），仅呈现形式不同。

## 模板

```markdown
# 语义事实报告：<项目名>

- 项目位置：<project>
- （若采用缺省）项目位置未提供，已采用宿主当前工作目录

## 项目层

### <事实类型>
- <字段>：<值>（证据：<文件:行号范围>）

## 模块层

### <事实类型>
- <字段>：<值>（证据：<文件:行号范围>）

## 符号层

### <事实类型>
- <字段>：<值>（证据：<文件:行号范围>）

## 事实层

### <事实类型>
- <字段>：<值>（证据：<文件:行号范围>）

## 缺口（gaps）

- <事实类型>：<原因>

## 超出范围（out_of_scope）

- <目录外引用的事实类型>
```

## 要求

- 按 fact-catalog 的层级组织（规范不预设层级，层级以目录为准）。
- 每条关键事实标注源码证据定位。
- gaps 与 out_of_scope 分列呈现，与机器可读事实集一一对应。
- 未要求的层不出现。
