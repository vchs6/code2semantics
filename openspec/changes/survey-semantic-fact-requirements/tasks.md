# Tasks

本清单由 `openspec instructions tasks --change survey-semantic-fact-requirements --json` 派生，执行依据为当前 `proposal.md` 与 `design.md`。这是主变更 `epic-layered-semantic-fact-skill` apply 在报告缺失时触发的上游依赖恢复；本清单就绪不代表报告存在。

**Goal:** 实际生成并验收 `research/semantic-fact-requirements.md`，供主变更消费。
**Architecture:** 按 design D1–D5，从消费者问题生成需求，核查材料，推导组织结论，再用场景及机械/语义检查验收。
**Tech Stack:** Markdown、web 一手来源核查、Python 3 标准库临时校验、OpenSpec CLI。
**Spec:** `proposal.md`；`design.md`。specs 已 skipped，不生成 spec delta。

**Global Constraints:** 禁止读取已删报告的 Git 内容或旧报告的分层/类型结论；禁止预设层数、名称、类型数或比较旧分层提案；每事实最多两项外部来源；不改 proposal/config/其它变更/产品代码，不 commit/push/archive。design Open Questions 是任务需要产出的研究结论，不预填答案。

**Review Focus:** 混合/重叠范围与多成员身份（2.1、4.1）；跨范围引用不扩大分析范围（2.1、4.1）；条件/循环关系不树化（2.1、4.1）；整体追溯到元素内部算法（2.1、4.1）；未知证据不等于不存在（2.1、2.2、4.1）。

以下任务 MUST 由本变更的 OpenSpec apply 按依赖顺序执行，每项产物实查通过后才更新对应 checkbox；报告生成与验证从 1.1 开始，阶段进度以 apply 和执行日志为准。
