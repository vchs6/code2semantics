# Spec Delta

## MODIFIED Requirements

### Requirement: 语义归纳的请求与并入

构造器 SHALL 对"存在待取值集合"的事实类型不自行归纳，而以结构化归纳请求显式声明所需归纳的事实类型、其待取值字段集合与依据信息。存在待取值集合的事实类型包括：无工具直出数据项的缺失事实类型（既有形态），以及类型已产出事实但存在值为空的归纳字段的混合形态（如依赖方向由工具直出、依赖类型需归纳）。归纳请求 SHALL 以事实类型为单位、以待取值字段集合为一组整体下发，MUST NOT 逐字段拆分为多条请求。归纳结果 SHALL 经契约校验后并入事实集，目录外事实类型 MUST 拒收；整组返回的结果 SHALL 回填到对应实体的空字段，回填成功的字段不再进 gaps。未被归纳覆盖的请求 SHALL 随输出显式暴露，未回填的待取值字段以字段级 gap 显式声明，MUST NOT 以猜测或占位填充。

#### Scenario: 整类型缺失产出结构化请求
- **WHEN** 某事实类型无工具直出数据项，且其生产者仅为语义归纳类
- **THEN** 构造器产出一条结构化归纳请求（含事实类型、待取值字段集合与依据信息），不自行编造该事实

#### Scenario: 混合形态的空缺归纳字段触发归纳
- **WHEN** 某事实类型已由工具直出产出部分事实，但其中存在值为空的归纳字段，且该事实类型存在已点亮的语义归纳类生产者
- **THEN** 构造器产出一条以该类型为单位的归纳请求，其字段集合为该类型本轮构造后仍待取值的字段

#### Scenario: 待取值集合整组下发不逐字段拆分
- **WHEN** 某事实类型的待取值字段集合包含多个字段
- **THEN** 构造器以一次归纳请求整体下发该字段集合，不产生按字段拆分的多条请求

#### Scenario: 归纳结果经契约校验后并入
- **WHEN** 归纳方返回事实集
- **THEN** 仅目录内且被请求的事实类型并入事实集，每条附证据；目录外类型被拒收

#### Scenario: 整组返回回填实体空字段
- **WHEN** 归纳方对混合形态事实类型的待取值字段集合整组返回结果
- **THEN** 构造器将返回值回填到该类型对应实体的空字段，回填成功的字段不再出现在 gaps 中

#### Scenario: 未覆盖请求与未回填字段保持显式
- **WHEN** 归纳请求未被覆盖，或整组结果中部分字段未返回
- **THEN** 未覆盖的请求随输出暴露，未回填的字段以字段级 gap 显式声明，不出现编造内容
