# Spec Delta

## Purpose

定义单一 layered-semantic-facts Skill 的自包含安装形态，使程序、按需文档、公共契约及矩阵数据能够随包分发并通过统一相对入口加载，在独立安装环境完成真实查询验证。包装拥有安装和加载边界，组件行为由各子变更交付，目录和元数据遵循 Agent Skills Specification。

## ADDED Requirements

### Requirement: Skill 目录自包含且可独立运行
Skill SHALL 是单一自包含安装单元，入口为 SKILL.md，程序位于 scripts/，按需文档位于 references/，数据和机读 schema 位于 assets/。外部工具与环境依赖 SHALL 通过 compatibility 声明；安装后不依赖开发仓库其余目录。包装不得重复实现查询、构造、解析、矩阵或仓库业务。

#### Scenario: 安装到独立环境后端到端查询可运行
- **WHEN** 完整 Skill 安装到不含开发仓库其他目录且满足声明环境的系统
- **THEN** 按主变更用例执行查询链，交付同一公共响应及真实缺口，不因仓库外路径缺失中断

#### Scenario: 程序代码位于 scripts 目录
- **WHEN** 检查完整安装包
- **THEN** 程序位于 scripts/，人读文档和数据分别位于 references/ 与 assets/，不依赖未声明开发路径

### Requirement: 组件与数据工件固定布局可寻址
Skill SHALL 通过以 Skill 根目录为锚的统一相对加载入口定位组件、文档、矩阵及公共契约，不在各组件散布路径拼凑。缺失对象 SHALL 返回可定位原因及期望位置；MUST NOT 隐式加载旧协议或仓库外替代文件。

#### Scenario: 组件与工件寻址成功
- **WHEN** 在不同安装位置请求相同组件和公共契约
- **THEN** 依统一布局加载同源内容，不依赖绝对开发路径

#### Scenario: 组件缺失可定位
- **WHEN** 安装包缺少必要组件或契约
- **THEN** 明确报告缺失对象与期望位置，不静默切换旧版本或其他路径

### Requirement: 契约权威单一
每种机读契约 SHALL 仅有一份由主变更拥有的权威资产，组件同源加载；最新契约直接替换旧协议并统一消费者，MUST NOT 保留分叉 schema、兼容入口、双轨或回退适配。包装不自行重新定义契约字段，当前旧资产在完成更新前不代表新契约可用。

#### Scenario: 编排层与构造器契约同源
- **WHEN** 查询及构造等组件加载其公共契约
- **THEN** 使用同一主设计权威资产，不私有复制或沿旧协议解释

### Requirement: 数据工件随更新同步生效
Skill SHALL 随重新安装或分发携带开发期固化的信息需求清单、权威矩阵及契约数据，运行期只读使用，不生成或扩展清单、不启动研究开发。开发期研究仅补未点亮说明；解析器开发流程完成接入验收后点亮，已点亮即验收可用且构造器可直接选用，不增设生产状态。运行、超时、重试、成功失败 SHALL 由执行器管理，不写成矩阵运行状态。

#### Scenario: 矩阵更新随重新安装生效
- **WHEN** 解析器完成接入验收并点亮工具后重新分发 Skill
- **THEN** 安装后的构造器按更新矩阵直接选用该工具，无需手工同步文件或额外生产门禁

#### Scenario: 执行失败不改变矩阵状态
- **WHEN** 已点亮工具在一次调用中超时或失败
- **THEN** 执行器报告运行结果，不将该运行态混入矩阵点亮定义

### Requirement: 目录布局与元数据符合业界规范
Skill SHALL 按 AGENTS.md 采纳的 Agent Skills Specification 约束 frontmatter、目录和渐进披露：name 与父目录一致，符合小写字母数字连字符及最多64字符限制；description 最多1024字符，说明做什么及何时使用；compatibility 声明环境要求；正文少于500行，细节下沉。符合性 SHALL 经官方 skills-ref validate，不能使用时经逐项规范检查表判定。

#### Scenario: 规范校验通过
- **WHEN** 检查 Skill 完整安装包
- **THEN** 官方校验通过或逐项检查表有可复核的符合性结论，无未说明违规

### Requirement: 安装加载验证与组件验收分工
包装 SHALL 检查完整安装环境的入口、组件、契约及数据加载，并消费各子变更交付开展主变更要求的真实端到端验证，不以路径可达替代事实生产或持久化重读。验证结果 SHALL 记录实际事实、证据和缺口，不增设矩阵生产状态，不假定尚未建成组件已交付。

#### Scenario: 加载成功仍需真实查询证据
- **WHEN** 组件路径检查通过
- **THEN** 继续以真实来源验证查询及入库重读，明确现有能力和 gap，而非只凭安装成功宣称完成集成
