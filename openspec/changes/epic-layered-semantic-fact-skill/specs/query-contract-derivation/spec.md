# Spec Delta

## Purpose

提供对话驱动的语义事实查询：从用户的自然语言对话中提取并补全查询契约，驱动契约查询模式，并以人可读的语义事实报告呈现结果。

## ADDED Requirements

### Requirement: 从对话中提取查询契约
Skill SHALL 能够从用户的自然语言对话中识别查询意图并形成查询契约。提取的契约 MUST 遵循与契约查询模式相同的契约结构（项目存储位置与所需事实描述）。

#### Scenario: 对话给出完整意图
- **WHEN** 用户在对话中描述想了解的事实（如"这个项目有哪些模块、入口在哪"）
- **THEN** Skill 将其整理为契约并按契约查询模式执行提取

#### Scenario: 项目位置缺省补全
- **WHEN** 对话中未提及项目存储位置
- **THEN** Skill 以宿主当前工作目录作为项目存储位置填入契约，并在结果中说明该缺省

### Requirement: 人可读的语义事实报告
Skill SHALL 返回人可读（Markdown）的语义事实报告。报告 MUST 与底层机器可读事实集在内容上一致，MUST 按可提供事实目录定义的层级组织（规范不预设层级），并 SHALL 为每条关键事实标注源码证据定位。

#### Scenario: 报告与事实集一致
- **WHEN** 同一契约经对话派生模式执行完成
- **THEN** 报告所述事实与对应机器可读事实集内容一致，仅呈现形式不同

### Requirement: 意图不明时的澄清
当对话中的查询意图不足以构成可执行的契约时，Skill SHALL 向用户提出澄清问题，MUST NOT 在意图不明时自行猜测并产出事实集。

#### Scenario: 意图不足
- **WHEN** 用户只表达模糊意图（如"帮我看看这个项目"）而未指明所需事实
- **THEN** Skill 列出可提供事实目录中的可选事实类型与典型契约示例，请用户明确后再执行
