# Spec Delta

## Purpose

让用户从自然语言表达当前项目或项目集合中的事实需求，形成与结构化模式一致的目标、观察粒度和字段契约，在意图不足时澄清，并仅在明确要求时从同一事实响应生成可复核的可读报告。

## ADDED Requirements

### Requirement: 从对话中提取查询契约
Skill SHALL 从对话提取用户给定当前项目或项目集合、查询目标、观察粒度及所需事实，形成与结构化模式相同的契约并执行校验；MUST NOT 绕过目录、覆盖、来源有效性和最小响应约束。解析到范围外引用不扩大授权；对话运行期不得通过查询触发信息需求清单扩展、工具研究、解析器开发或点亮，未覆盖需求保留缺口交开发期变更处理。

#### Scenario: 明确当前事实需求
- **WHEN** 用户要求指定项目集合在某观察粒度的用途与交互事实
- **THEN** 形成可检查的同一查询契约并固定本次目标与粒度，不自动展开更深后代

### Requirement: 观察范围缺省标注
用户未提供分析位置且意图足以执行当前查询时，Skill SHALL 以调用时当前工作目录作为明确标注的缺省范围；MUST NOT 将该目录自动等同于唯一项目或工作空间，不推导用户历史快照或版本请求。

#### Scenario: 混合目录缺省
- **WHEN** 用户未给位置，当前目录含多个项目和共享单元
- **THEN** 标注缺省观察范围，依据边界证据分别识别项目与单元

### Requirement: 意图不明时的澄清
无法确定可执行的目标、观察粒度或所需事实时，Skill SHALL 提供目录内选项和示例并澄清；MUST NOT 擅自猜测事实需求或扩展分析范围。

#### Scenario: 模糊请求
- **WHEN** 用户只说帮我看看且无法确定事实需求
- **THEN** 先澄清目标、粒度或字段，不执行猜测出的事实提取

### Requirement: 人可读的语义事实报告
默认输出 SHALL 是机器可读事实响应；仅用户明确要求时 SHALL 从同一响应生成可读报告，保留身份、必要 context、coverage、basis、来源性质、知识状态、证据和缺口，不补写未返回或未证实事实，不改变契约与观察粒度。

#### Scenario: 默认机器结果
- **WHEN** 对话已形成有效查询但用户未请求报告
- **THEN** 返回同一机器事实响应，不强制附加报告

#### Scenario: 报告保留不足与否定条件
- **WHEN** 用户要求报告且响应含证据不足、冲突或限定不存在
- **THEN** 报告保留这些状态、检查覆盖和可复核依据，不将解释改写为已证明结论
