```json

}
```

```json
{
  "project": "/home/vchs6/code2semantics",
  "project_defaulted": false,
  "facts": {
    "项目": [
      {
        "type": "项目用途/领域",
        "fields": {
          "name": "code2semantics",
          "domain": "提供按查询契约从项目源码提取最小、分层、语言无关语义事实集的能力（Skill 仓库）；项目在进入设计前以事实集需求调研为起点，事实需求由语义表达目标决定"
```
